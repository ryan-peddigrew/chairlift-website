# 3. Proposals

**Owner:** not set in the action items (suggest Ryan to draft, each rep to use) · **Target:** by 2027
**Status:** Four reusable templates drafted: General, Festivals, General Consumer, Corporate / Conference.

## Rules for every proposal
- Pricing shows **quantities and totals only, no per-unit rates** (matches the "Quotation - MSS Deal" PDF format from Current RMS). Attach the RMS quote as the price page.
- Strip anything internal before it goes out: pricing status, OWN / X-RENT tags, "need X" notes.
- Tie every proposal back to the four pillars: Audio, Video, Lighting, Staging (playbook section 2).
- At least one case study matched to the event type (playbook Appendix E format), only with client approval.
- A second team member reviews scope and pricing before sending (playbook Appendix D).
- Canadian spelling, CAD, HST shown separately.
- Brackets `[ ]` are fill-ins. Delete any section that doesn't apply.

| Template | Use for | File |
|---|---|---|
| General | Any inbound request that doesn't fit the others; short-form | `general.md` |
| Festivals | Festivals, BIA street events, Ribfest circuit, outdoor concerts, municipal events | `festivals.md` |
| General Consumer | Weddings, galas, private parties, milestone events | `consumer.md` |
| Corporate / Conference | Meetings, conferences, AGMs, launches, hybrid events, RFP responses | `corporate-conference.md` |
