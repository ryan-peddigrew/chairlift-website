# Open house: run sheet and day-of checklist

## Roles (fill names)
| Role | Name | Job |
|---|---|---|
| Event lead | | Owns the day, final calls |
| Host / MC | | Introduces spotlights and music, thanks guests |
| Walk-through guides (2) | | 4:30 and 6:30 tours, 20 minutes each |
| Sign-in | | QR sign-in, name tags, captures who came |
| Stage tech (audio) | | Mixes spotlights and music |
| Stage tech (lighting / video) | | Looks, LED loop, presenter slides |
| Photographer / video | | Shot list below |
| Floor reps (every sales rep) | | Talk to guests, book next steps |
| Bar / catering contact | | Service and licence compliance |

## The week before
- [ ] Final RSVP list exported; do-not-contact check done
- [ ] Name tags printed (colour code: client / prospect / vendor / staff)
- [ ] Sales sheets printed: capabilities, sound stage, segment one-pagers
- [ ] LED loop built: real show photos and clips (approved only)
- [ ] Spotlight slides collected from vendors
- [ ] Walk-through route set and safe: clear aisles, no live rigging, hazards taped off
- [ ] Bar licence / special occasion permit in hand if serving alcohol; licensed bartenders booked
- [ ] Music act confirmed; set times and rider covered
- [ ] Parking, signage and coat area arranged
- [ ] Full rehearsal of both show moments (day before)

## On the day
| Time | Check |
|---|---|

| 7:15 | Music set #2 |
| 8:00 | Close; reps log every conversation in HubSpot tonight |

## Photo and video shot list
- Wide of the stage with a full room (from the back, no faces close up without consent)
- Stage rig detail: lighting, PA, LED
- Walk-through group in the shop
- Each vendor spotlight on stage
- Music set, two angles
- 15 to 30 second clip for LinkedIn
Follow the tech photo policy: consent for close-ups; post only approved shots.

## Sales capture (every rep)
For each conversation, log in HubSpot: name, company, event type, next event date, what they asked about, agreed next step and date.
Goal: every Hot Lead attendee has a dated next step within 7 days.
